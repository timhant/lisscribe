# 干净机器验收清单

在**从未装过 .NET SDK / Visual Studio** 的 Windows 机器上验证发布产物。

这是唯一能提前抓住 DLL 加载问题的办法——开发机的输出目录里恰好躺着那些 DLL，
所以本地永远测不出来。**本项目已经因此在另一台机器上栽过一次**（见 C 组）。

准备：在开发机跑 `powershell -ExecutionPolicy Bypass -File scripts\publish.ps1`，
把 `dist\lisscribe-<版本>-win-x64.zip` 拷到目标机器解压。（**别写成 `pwsh`**：PowerShell 7 要另装，
而这套脚本的服务对象恰恰是只有 5.1 的干净机器。）

拿 zip 而不是拷目录，验的才是用户真正会拿到的那个东西——包括解压后目录结构对不对。

---

## A. 启动与依赖

- [x] **A1** 双击 `Lisscribe.App.exe` → 正常启动，**无 0xC000007B、无 DllNotFoundException**
- [ ] **A2** 托盘出现图标；右键菜单九行：打开配置 / 转写音频文件… / 暂停热键 / ── /
      打开模型目录 / 打开日志目录 / 关于 lisscribe / ── / 退出
- [ ] **A3** 首次启动生成 `config.json`（验的是 `File.Replace` 的首次写入分支——
      那条路径与「覆盖已有文件」走的不是同一段代码）
- [ ] **A4** 把 `dist\` 放到 `C:\Program Files\` 下（只读目录）运行 → 提示目录不可写并退出，
      **不崩溃**
- [ ] **A5** 从托盘退出 → 进程正常结束，任务管理器中无残留，**不弹崩溃对话框**

## B. 模型

- [ ] **B1** 未放模型时启动 → 悬浮条红色提示，文案里**点名少了哪个文件、在哪个目录找的**，
      程序不崩溃
- [ ] **B2** 托盘「打开模型目录」→ 资源管理器打开该目录；**目录原本不存在时它会先建出来**
      （这一项正是给「模型没放对地方」的人准备的，那时目录多半还不存在）
- [ ] **B3** 按 `models\README.txt` 放入 SenseVoice 权重后重启 → 日志出现「模型加载完成」
- [x] **B4** 按住 `Ctrl+Alt+Space` 说一句话 → 文本正常上屏
- [ ] **B5** 换 Qwen3 档（配置窗改识别引擎 → 弹窗问重启 → 确认）→ 重启后能识别；
      配置窗里那行灰字随之变成「该档单次最长可录 25 秒」

## C. 中文安装路径（**必验，这条是在真机上栽出来的**）

把 `dist\` 放到一个**含中文的目录**下再跑一遍 A、B 两组，例如 `D:\我的程序\lisscribe\`。

- [x] **C1** 中文目录下能正常识别上屏（不是只看「启动成功」——见下面这条判据）
- [ ] **C2** 日志里那行「模型加载完成，耗时 …」的**耗时读数合理**：SenseVoice 约 1.1–1.7 秒、
      Qwen3 约 4.2–4.7 秒。**读到几十毫秒就是没真加载**——那个数连把权重读一遍都不够。

> **为什么单列一组。** 病根是两件事叠起来：sherpa-onnx 在 Windows 上按窄字符查模型文件，
> 中文路径一律判「不存在」；而它建不出识别器时**既不抛也不报**，`OfflineRecognizer` 构造器
> 不检查原生返回值，照样把空句柄裹成对象交出来。于是日志上「加载完成」是假的、`IsLoaded`
> 也是真的，错误一直推迟到**每次识别**才从一个不含任何原因的 `NullReferenceException` 里炸出来。
> 现已修好（切工作目录 + 建器后自检），但**这条修复只有在中文路径下跑真识别才验得到**，
> 只看「启动成功」照样绿。修法与四条否掉的路见 `NativeModelDirectoryScope` 的注释。

## D. 文件转写

解码靠系统自带的 Media Foundation，开发机上有它不代表用户机器上有，所以在干净机器上单验一组。
准备一个几分钟长的 `.m4a`（手机录音即可）和一个 `.mp3`。

- [ ] **D1** 托盘「转写音频文件…」→ 选择文件对话框**弹在最前面**；筛选项有「音频文件」与「所有文件」
- [ ] **D2** 选 `.m4a` → 悬浮条蓝色「转写中 xx%」加滚动条；转完自动打开 txt，文件在 exe 旁边的
      `transcripts\` 里，名字是 `<音频名>-<年月日时分秒>.txt`，每行 `[hh:mm:ss] 文字`
- [ ] **D3** `.mp3` 同上走一遍
- [ ] **D4** 转写中按热键 → 不开始录音
- [ ] **D5** 转写中托盘「取消转写」→ 一两秒内停下，不打开任何文件，`transcripts\` 里**没有 `.part` 残留**
- [ ] **D6** 在中文安装路径下（C 组那个目录）再做一次 D2
- [ ] **D7**（有条件时）在 Windows N 版本上选 `.m4a` → 红条说明打不开、程序不崩溃；装上
      Media Feature Pack 后能转
